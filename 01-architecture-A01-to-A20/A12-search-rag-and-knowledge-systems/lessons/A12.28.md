## 3. Step-by-step mechanism & minimal dry-run

Freshness depends on source update, queue, indexing, publication and cache invalidation. An index revision can be included in cache identity.

**Trace.** source revision → index revision → cache key → current result.

## 4. Formal rigor & quantitative math

An update taking 3 s to index and 2 s to invalidate can remain stale for roughly 5 s along that serial path.

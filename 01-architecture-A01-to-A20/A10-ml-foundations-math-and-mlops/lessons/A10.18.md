## 1. The problem & why it exists

A deployment pulls an artifact called latest and unexpectedly changes behavior. Promote verified versions and capture the exact version each request used.

## 3. Step-by-step mechanism & minimal dry-run

A model registry associates immutable versions with metadata, artifacts and mutable references such as aliases. Promotion should require evaluation and compatibility evidence.

**Trace.** run artifact → registered version → validated promotion → deploy.

## 4. Formal rigor & quantitative math

Three replicas following one mutable alias can converge to a new model at different times; one pinned version gives one defined artifact.

Predict the worked quantities by hand, then run the [example](../examples/A10.18.py). It uses a small calculation or state model. For arithmetic, retain the units attached to the worked formula.

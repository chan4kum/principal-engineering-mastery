## 1. The problem & why it exists

A model fits storage capacity but exceeds the serving runtime's memory. Profile representative workloads and price with current measured resource use.

## 3. Step-by-step mechanism & minimal dry-run

Weight, activation, cache and runtime storage budgets differ. Training also spends on gradients and optimizer state. Cost depends on actual utilization, duration and infrastructure rates.

**Trace.** parameter count and precision → memory estimate → profile and budget.

## 4. Formal rigor & quantitative math

A 1-billion parameter model at two bytes/parameter has a raw weight footprint of about 2 GB decimal before runtime state.

Predict the worked quantities by hand, then run the [example](../examples/A10.35.py). It uses a small calculation or state model. For arithmetic, retain the units attached to the worked formula.

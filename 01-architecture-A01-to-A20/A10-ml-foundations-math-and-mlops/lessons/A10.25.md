## 3. Step-by-step mechanism & minimal dry-run

Self-attention compares token queries with keys, then combines value vectors. Standard full score arrays grow quadratically in sequence length.

**Trace.** token representations → Q K V → attention scores → combined values.

## 4. Formal rigor & quantitative math

Doubling sequence length from 128 to 256 quadruples the dense score count, from 16384 to 65536 per head.

Predict the worked quantities by hand, then run the [example](../examples/A10.25.py). It uses a small calculation or state model. For arithmetic, retain the units attached to the worked formula.

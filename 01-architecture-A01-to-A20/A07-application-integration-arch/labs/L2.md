# L2 · Messaging semantics

From the repository root:

```sh
bash 01-architecture-A01-to-A20/A07-application-integration-arch/labs/streams.sh
```

Run the private Redis Streams fixture. Worker A reads without acknowledging, so the pending list holds an entry. Worker B reclaims it with the same stream ID and acknowledges it. Record pending counts, the delivery ID, and stream length. Acknowledgment removes the pending record, while stream retention follows separate rules. Zero minimum idle time deliberately injects immediate redelivery; use a meaningful lease in a real worker.

Predict the response or state before running. Record normal, broken and recovered evidence and name the boundary that controls the outcome. Scratch variants and pytest data can be discarded after recording evidence. The Redis container is private and self-removing.

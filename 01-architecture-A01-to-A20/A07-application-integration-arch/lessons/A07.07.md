## 3. Step-by-step mechanism & minimal dry-run

Layers group responsibilities and constrain dependencies. Transport translates requests, application code coordinates use cases, domain code protects invariants and infrastructure handles storage or remote side effects.

**Trace.** transport → application → domain; infrastructure reached behind a port.

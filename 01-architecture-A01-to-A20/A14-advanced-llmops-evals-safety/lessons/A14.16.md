# A14.16 · streaming metrics

[A14.15](A14.15.md) · Core · [A14.17](A14.17.md)

## Problem

Generation streams produce slow gaps hidden by average throughput.

## Mechanism

Timestamp request submission, first token and each later token at the consumer. Separate time to first token, inter-token gaps and completion time.

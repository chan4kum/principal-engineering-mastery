## 1. The problem & why it exists

A server reaches its descriptor limit while CPU remains mostly idle. Close descriptors promptly and bound concurrent connections. Increasing limits only buys headroom for legitimate demand.

## 3. Step-by-step mechanism & minimal dry-run

An FD is an index in a process table. It refers to an open file description or kernel object such as a socket.

**Trace.** socketpair -> two FDs -> send 2 bytes -> receive 2 bytes -> close sender -> receiver sees EOF after buffered data.

**Boundary case.** On EOF, treating empty bytes as retryable can busy-loop. Finish the read side and release resources.

## 4. Formal rigor & quantitative math

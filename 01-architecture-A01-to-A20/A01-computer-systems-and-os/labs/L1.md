# L1 · Process anatomy

**Question:** Which entry records a child's parent and how does a terminating signal change the status the parent collects? Use a Linux terminal for `/proc`, or run via a local Docker engine.

```sh
LAB=01-architecture-A01-to-A20/A01-computer-systems-and-os/labs
docker run --rm --network none --pids-limit 32 -v "$PWD/$LAB:/lab:ro" python:3.12-slim python /lab/process_anatomy.py
docker run --rm --network none --pids-limit 32 -v "$PWD/$LAB:/lab:ro" python:3.12-slim python /lab/process_anatomy.py --break
```

1. Predict the relationship between PID and PPID. Compare the parent's printed PID with the child's `PPid` field.
2. Compare exit 0 to negative 15 from the terminated child. Python's POSIX return code uses negative signal numbers.
3. Rerun the normal variant. Extend the trace by launching a grandchild from the child and printing its PPID. Then predict what would happen to a surviving child if the parent exited first. On Linux it can be reparented to namespace init or a subreaper, depending on configuration. If the parent is namespace PID 1 and exits, remaining tasks in that namespace are killed.
4. Record both statuses and the namespace scope. The script waits for its own child, and the container removes itself on exit.

# A19.23 · memory-mapped weights

[A19.22](A19.22.md) · Principal · [A19.24](A19.24.md)

## Problem

Mapping weights is assumed to make the full file resident.

## Mechanism

Memory mapping creates an address mapping. Pages are brought in on access as the system needs them; measure faults and resident memory separately from virtual size.

# L1 · Cache benchmark

From the repository root:

```sh
LAB=01-architecture-A01-to-A20/A05-scalability-caching-performance/labs
uv run python "$LAB/benchmarks.py" L1
```

Compare no cache, a three-entry cache for a three-key hot set, and a one-entry cache under the same cyclic access pattern. Predict the hit counts, then record p50 and hits divided by requests. TTL is checked at read time; capacity can evict younger entries. Change only the TTL or capacity and repeat. This benchmark uses a local cache and simulated origin delay. Use the Redis companion below for real server expiry behavior.

Save the normal, failure and repaired measurements. Keep the workload and units fixed apart from the changed input. Remove any scratch variants.

With Docker available, run `bash "$LAB/redis.sh"` after setting the variable above. The isolated server demonstrates a real key hit, an explicit expiry that forces a miss, and refill. It has no published host ports and is removed after the check. It can pull the image the first time.

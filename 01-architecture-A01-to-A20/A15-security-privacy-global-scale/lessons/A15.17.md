# A15.17 · rate limits and abuse protections

[A15.16](A15.16.md) · Core · [A15.18](A15.18.md)

## Problem

One caller exhausts shared worker capacity.

## Mechanism

Apply scoped rate and concurrency limits with explicit cost units, bounded queues and fair allocation. A distributed limiter must define behavior during store failure.

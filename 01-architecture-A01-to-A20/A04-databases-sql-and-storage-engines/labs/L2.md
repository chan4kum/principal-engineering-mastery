# L2 · Isolation

Run from the repository root with Docker.

```sh
LAB=01-architecture-A01-to-A20/A04-databases-sql-and-storage-engines/labs
bash "$LAB/run.sh" L2
```

Start with 5 units. One transaction reads 5, waits, then writes a stale constant after a second transaction has decremented. The final value is 4. Replay the missed effect using an atomic update and observe 3. Next, predict the cycle when two sessions take locks in opposite order. Observe SQLSTATE 40P01 and verify that retrying in consistent order succeeds. In a variant, compare Repeatable Read and Read Committed when a second session inserts a matching row.

Record normal, failed and repaired observations with the statement order or elapsed units. The runner uses a private PostgreSQL container without published ports and removes it and its anonymous volume when it exits. Remove scratch variants after recording the evidence.

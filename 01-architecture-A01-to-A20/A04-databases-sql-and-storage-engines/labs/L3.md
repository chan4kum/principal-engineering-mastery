# L3 · Crash recovery

Run from the repository root with Docker.

```sh
LAB=01-architecture-A01-to-A20/A04-databases-sql-and-storage-engines/labs
bash "$LAB/run.sh" L3
```

Predict whether a committed marker and an uncommitted marker survive. The script confirms that the second writer is sleeping before COMMIT, sends SIGKILL to the private container and restarts with the same storage volume. The committed marker survives and the uncommitted marker is invisible. Repeat with both markers committed. This simulates an abrupt process failure with intact local storage. Backup restore and host power loss are separate drills.

Record normal, failed and repaired observations with the statement order or elapsed units. The runner uses a private PostgreSQL container without published ports and removes it and its anonymous volume when it exits. Remove scratch variants after recording the evidence.

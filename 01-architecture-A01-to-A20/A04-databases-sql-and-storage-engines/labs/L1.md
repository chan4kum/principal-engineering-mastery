# L1 · Query plan

Run from the repository root with Docker.

```sh
LAB=01-architecture-A01-to-A20/A04-databases-sql-and-storage-engines/labs
bash "$LAB/run.sh" L1
```

Predict an unindexed equality plan, the same lookup after creating an index, and a Boolean predicate matching nearly every row. The fixture inserts 30,000 rows and runs ANALYZE. Compare node type, estimates, actual rows, loops, and buffers. The wide Boolean query tests the assumption that every existing index is useful. Vary selectivity and verify whether the plan changes. EXPLAIN ANALYZE executes the statement.

Record normal, failed and repaired observations with the statement order or elapsed units. The runner uses a private PostgreSQL container without published ports and removes it and its anonymous volume when it exits. Remove scratch variants after recording the evidence.

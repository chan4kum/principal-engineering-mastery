# L3 · Consensus simulation

```sh
LAB=01-architecture-A01-to-A20/A06-distributed-systems-coordination/labs
uv run python "$LAB/coordination.py" L3
```

The model starts with one fixed leader and one term. Separate the leader from the followers, append a value, and predict the empty visible commit prefix. Restore one follower and observe majority commitment. Calculate the threshold for five nodes and test the same failure. This models prefix visibility and majority acknowledgment. Raft election, durable terms and conflict repair are separate protocol rules.

Record the predicted and observed results, including the observer or authority boundary. Rerun a changed normal control as a repair and remove any scratch variant. The fixture shuts down on exit.

Predict each identity and value in this REPL trace.

```python
original = [[1]]
alias = original
shallow = original.copy()
print(alias is original, shallow is original, shallow[0] is original[0])
shallow[0].append(2)
print(original)
```

The identity results are true, false and true. The unexpected append reaches the original. Repair it by rebuilding with `[row.copy() for row in original]`. Predict and test whether a second append is visible. Contrast rebinding a name with mutating a shared object.

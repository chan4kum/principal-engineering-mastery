# M12 L4 · ML transfer

[Module index](../README.md)

Evaluate calibration for a bin of 100 forecasts with probability 0.8. Change the number of positive outcomes from 80 to 60 and measure the absolute gap.

Write both predictions before running from the repository root. The changed-input command checks that the experiment detects the intended difference.

```sh
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L4
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L4 --break
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L4
```

Record the first differing value, the assumption that changed, and the restored result. Then change one additional input and explain the result before checking it.

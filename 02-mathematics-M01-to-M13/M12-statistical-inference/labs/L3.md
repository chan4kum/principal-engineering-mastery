Write both predictions before running from the repository root. The changed-input command checks that the experiment detects the intended difference.

```sh
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L3
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L3 --break
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M12 lab L3
```

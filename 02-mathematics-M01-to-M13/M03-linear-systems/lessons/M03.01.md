# M03.01 · matrices as linear maps

[Phase index](../README.md) · Foundation · [M03.02](M03.02.md)

## Problem

Dimensions are lost when a matrix is treated as a table.

## Mechanism

An m×n real matrix represents a linear map from Rⁿ to Rᵐ. Each row computes an output coordinate and columns are images of standard basis vectors.

## Worked example

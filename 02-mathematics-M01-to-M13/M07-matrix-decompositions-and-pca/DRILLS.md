# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. Find the singular values of diag(6,−k) for k = 0, 1, 2, 3, 4.
2. Find the best rank-one Frobenius error of diag(6,k,1) for k = 1, 2, 3, 4, 5.
3. For k = 1, 2, 3, 4, 5, compare factor storage k(100+50+1) with dense storage 5,000.

# M07 applied assessment

[Module index](README.md)

Attempt all five cases independently before opening feedback. Award one point per correct result with reasoning. Four points meet 80%. Use changed inputs for a delayed re-test.

1. Find the rank of diag(4,0,−2).
2. Find the best rank-one Frobenius error for diag(8,3,4).
3. How many scalars are in the compact rank-two factors for a 20×10 matrix?
4. For five centered rows, find sample variance along a direction with singular value 6.
5. Find the rank of a centered sample matrix whose rows were all equal before centering.

# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. Find the Euclidean norm of (5,k) for k = 0, 1, 2, 3, 4.
2. Compute (1,−2) · (k,3) for k = −2, −1, 0, 1, 2.
3. For k = −2, −1, 0, 1, 2, find the rank of [[2,4],[1,2+k]]. State a basis for its null space when k = 0.

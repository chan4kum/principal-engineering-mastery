# M09 applied assessment

[Module index](README.md)

Attempt all five cases independently before opening feedback. Award one point per correct result with reasoning. Four points meet 80%. Use changed inputs for a delayed re-test.

1. Differentiate (2x+1)³ at x=0.
2. Find the gradient of xy² at (2,3).
3. State the Jacobian shape for a map from ℝ³ to ℝ².
4. Find the Hessian of x²+y².
5. Minimize x²+y² subject to x+y=6.

<details>
<summary>Answers and rationale</summary>

1. 6.
2. (9,12).
3. 2×3.
4. diag(2,2).
5. The minimizer is (3,3), with value 18.

</details>

# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. Compute the derivative of x²+3x at x = −2, −1, 0, 1, 2.
2. Compute ∇(x²+2y²) at (k,1) for k = −2, −1, 0, 1, 2.
3. For k = 0, 1, 2, 3, 4, minimize x²+y² subject to x+y=2k.

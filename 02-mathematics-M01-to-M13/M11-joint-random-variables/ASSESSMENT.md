2. Using those values, find P(Y=1|X=1).
3. If Cov(X,Y)=1 and both standard deviations are 2, find correlation.
4. If Var(X)=3, Var(Y)=4, and Cov(X,Y)=−1, find Var(X+Y).
5. If X has mean 2 and variance 3, give mean and variance of 2X−1.

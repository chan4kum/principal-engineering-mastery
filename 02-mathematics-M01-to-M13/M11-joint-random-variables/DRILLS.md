# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. For c = −1, −0.5, 0, 0.5, 1, find the variance of X+Y for unit variances and covariance c.
2. For those same five covariance values, find the variance of X−Y.
3. For k = 0, 1, 2, 3, 4, find the variance of kX+3 when Var(X)=2.

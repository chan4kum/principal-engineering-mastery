# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. For points x=[1,2], y=[2,4], compute unpenalized mean squared error at w = 0, 1, 2, 3, 4.
2. Compute one gradient step from w=0 for L=(w−3)² at η = 0, 0.1, 0.25, 0.5, 1.
3. Minimize (w−4)²+λw² for λ = 0, 1, 2, 3, 4.

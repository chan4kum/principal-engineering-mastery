# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. Find the eigenvalues of diag(k,3) for k = −2, −1, 0, 1, 2.
2. Apply diag(1/2,−1/2) exactly k times to (1,1) for k = 0, 1, 2, 3, 4.
3. For A = [[2,k],[k,2]] and k = 0, 1, 2, 3, 4, find eigenvalues using directions (1,1) and (1,−1).

# M05 L2 · NumPy verification

[Module index](../README.md)

Reconstruct [[2,1],[1,2]] from its symmetric eigenpairs. Reverse the eigenvalues while keeping the eigenvectors in place and measure the Frobenius error.

Write both predictions before running from the repository root. The changed-input command checks that the experiment detects the intended difference.

```sh
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M05 lab L2
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M05 lab L2 --break
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M05 lab L2
```

Record the first differing value, the assumption that changed, and the restored result. Then change one additional input and explain the result before checking it.

# Numerical drills

[Module index](../README.md)

Work all 15 variations by hand before checking with NumPy. Label units, dimensions, or conditioning assumptions where they apply.

1. Project (k,2) onto (1,0) for k = −2, −1, 0, 1, 2.
2. Fit a constant to [1,3,k] by least squares for k = 0, 1, 2, 3, 4.
3. Compute cosine similarity of (1,k) and (1,0) for k = 0, 1, 2, 3, 4.

[Module index](../README.md)

Find the mean and variance of values 0 and 4 with probabilities 0.5 each. Change the second probability to 0.4 and reject the resulting mass assignment.

Write both predictions before running from the repository root. The changed-input command checks that the experiment detects the intended difference.

```sh
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L2
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L2 --break
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L2
```

Record the first differing value, the assumption that changed, and the restored result. Then change one additional input and explain the result before checking it.

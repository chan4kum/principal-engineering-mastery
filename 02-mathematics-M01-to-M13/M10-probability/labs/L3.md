# M10 L3 · Parameter sweep

[Module index](../README.md)

Use a population of ten with 2, 4, or 8 marked items. Compare the two-marked probability with and without replacement at each population composition.

Write both predictions before running from the repository root. The changed-input command checks that the experiment detects the intended difference.

```sh
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L3
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L3 --break
uv run --locked --extra math python 02-mathematics-M01-to-M13/verify.py M10 lab L3
```

Record the first differing value, the assumption that changed, and the restored result. Then change one additional input and explain the result before checking it.
